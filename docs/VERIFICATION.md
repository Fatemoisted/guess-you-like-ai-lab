## 发现并修正的问题

1. 初次浏览器测试发现：输入价格后，在部分输入路径中卡片仍保留旧值。将同步改为`input`事件即时重算，保留光标，并再次验证98、128和168元。
2. 手机断点中“已知事实”标题与输入标签重叠。改为明确的样式类，移除脆弱的按标签序号选择方式。
3. 手机屏幕上输入区先占据较长空间。将卡片对比提前，输入与解释放在其后。
4. 放大价格条件、事实与风险说明字号，提高可读性。
