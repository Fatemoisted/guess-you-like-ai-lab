# 猜你喜欢 · AI 卡片优化工作台

从真实推荐 Feed 观察出发，展示如何把封面图、主标题、推荐理由和价格行变成**有依据、可验证的决策信息**。

这是独立的面试 / 产品方案演示，不是美团官方产品。未连接美团业务系统，没有真实订单、商家核验或线上增长数据。

![工作台预览](docs/workbench-desktop.jpg)

## 运行

需要 Node.js 20+，**没有第三方运行依赖，不需要 npm install**。

```sh
npm start
```

打开终端显示的 `http://127.0.0.1:4173`。不要直接双击 HTML；页面使用 ES Modules。

```sh
npm run check
npm test
```

服务只监听本机。端口可通过 `PORT` 环境变量指定。

## 作品内容

| 模块 | 已实现 |
| --- | --- |
| 4 个案例 | 蛋挞商品、代金券、烘焙店铺、可编辑双人套餐 |
| 四元素优化 | 前后对比、点击元素查看技术 / 价值 / 风险 / 控制 |
| 场景选择 | 默认、带娃、停车、午餐；不改变身份、价格规则和使用限制 |
| 价格规则 | 以整数分计算，校验门槛、资格、有效性；区分面额 / 售价 / 人均 |
| 证据约束 | 每条理由有来源；事实移除后旧理由不再有效 |
| 异常处理 | 优惠过期、无资格、证据缺失、图片标签不匹配、报价失效 |
| 人工审核 | 接受、拒绝、编辑与重新校验；确认仅作用于演示 |
| 业务验证 | A/B 设计、核销指标、风险护栏、成本与优先级 |
| 验收 | 页面 12 项可执行规则自检、Node 自动测试、浏览器验证记录 |
| 交付 | 3 分钟导览、本地操作记录及 JSON 导出 |

默认模式是**确定性规则演示**。AI 图片是预先生成的示意素材；当前页面没有在线视觉识别、OCR、RAG 检索或图像编辑。解释面板区分当前实现与拟上线能力。

## 可选：接入真实语言模型

服务端适配器接受兼容 Chat Completions 格式的提供方。在项目根目录复制 `.env.example` 为 `.env`，自行在本机填写端点、模型名和密钥，然后：

```sh
node --env-file=.env server.mjs
```

密钥只由服务端读取，不发送给浏览器，不写入导出记录，`.env` 已排除版本控制。

真实模型的边界刻意较窄：**在当前有效、已经核实的候选理由中选择一个编号**。服务器对返回编号进行白名单验证，不允许模型生成或更改价格。请求超时、返回格式错误或无效编号时，界面回退到可追溯规则候选。

未配置真实提供方时不会伪造调用或加载进度。适配器已实现，但本次未连接真实付费模型，不宣称已完成外部提供方验收。

## 静态部署

`index.html`、`app/`、`assets/` 可直接部署到静态服务器，支持仓库子目录路径。静态版本保留完整规则演示，不具备服务端模型调用。

`docs/workflows/` 提供 CI 与 GitHub Pages 工作流模板。它们**不是已启用的自动化**；需要使用者按仓库权限将模板复制到 `.github/workflows/` 并设置 Pages。私有仓库的 Pages 可用性依账户计划而异。仓库公开范围与网站公开范围应分别确认。

## 数据边界

- 用户提供的三张截图只用于人工观察卡片结构与可见文案；**原图没有放入仓库**。
- 未保存原截图中的搜索词、精确位置、通知及其他周边个人信息。
- 所有可交互商家与交易数据均为虚构。截图中的价格现象仅构成待核验假设，不能据此认定平台价格错误。
- 来源编号表示案例内部出处，不代表真实平台认证。
- 操作记录只保存在当前浏览器的 localStorage；可清空或自行导出，不上传服务器。
- 不生成虚构 A/B 收益，不把有限的离线测试当作线上零风险保证。
